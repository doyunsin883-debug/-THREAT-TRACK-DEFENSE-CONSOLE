## 프로젝트 목적

처음에는 초음파 센서를 연결해서 거리값을 읽는 간단한 실험이었다. 그런데 시리얼 모니터에서 숫자가 바뀌는 것을 확인하고 나니, 그 숫자로 조금 더 의미 있는 판단을 해보고 싶었다. 물체가 가까이 있는지뿐 아니라 얼마나 빠르게 다가오는지도 알 수 있다면 경고를 더 직관적으로 만들 수 있을 것 같았다. 그래서 접근 속도와 TTC 계산을 더하고, 그 결과를 LED·부저·PC 화면으로 연결했다.

## 1. 실제 하드웨어 구성

| 부품 | 연결 | 구현 역할 |
|---|---|---|
| Arduino UNO | USB 통신 | 초음파 트리거, 에코 펄스 측정, 경보 제어 |
| HC-SR04 | D2 TRIG, D3 ECHO, 5V, GND | 정면의 물체까지 거리 측정 |
| 빨간 LED | D4 + 직렬 저항 | 위험(DANGER) 표시 |
| 노란 LED | D5 + 직렬 저항 | 주의(WARNING) 표시 |
| 초록 LED | D6 + 직렬 저항 | 안전(SAFE) 표시 |
| 저전류 피에조 부저 | D7, GND | 위험 단계에 따른 소리 패턴 |

[실제 제작 사진](../assets/screenshots/hardware-prototype.jpg) · [배선 CAD 이미지](../assets/diagrams/wiring-cad.png) · [편집 가능한 DXF](cad/threat-track-schematic.dxf)

센서, LED, 부저의 접지는 브레드보드 GND 레일을 통해 함께 연결했다. 각 LED에는 **반드시 저항을 하나씩 직렬로 삽입**한다. 브레드보드 부저 배치는 `e27=+`, `e30=-`, `a27→D7`, `a30→GND 레일`로 설명할 수 있다. 이 위치는 부저 연결 사례이며 모든 점퍼선의 1:1 실측 모델은 아니다.

## 2. 측정 원리와 계산

```text
거리(cm) = 초음파 에코 왕복시간(μs) × 0.0343 / 2
평활 거리 = 0.4 × 새 거리 + 0.6 × 이전 평활 거리
순간 접근 속도(cm/s) = (이전 거리 − 현재 거리) / 측정 간격(초)
평활 속도 = 0.5 × 순간 접근 속도 + 0.5 × 이전 평활 속도
TTC(초) = 현재 거리 / 접근 속도  (접근 속도 > 10 cm/s에서만 계산)
```

속도가 **양수이면 센서 쪽으로 접근**, 음수이면 멀어지는 것으로 정의했다. 초음파 거리 오차가 연속 차분에서 크게 증폭될 수 있어 지수평활을 사용했다. TTC는 현재의 추정 접근 속도가 유지되고 물체가 센서축 방향으로 움직인다는 단순 모델이므로, 실제 충돌 예측 성능으로 과장하지 않았다.

## 3. 경보 판정과 피드백

| 단계 | 코드 판정 조건 | LED | 부저 |
|---|---|---|---|
| SAFE | 거리 > 70cm, TTC 경고 없음 | 초록 | 무음 |
| WARNING | 거리 ≤ 70cm 또는 TTC ≤ 3초. 단 DANGER 제외 | 노랑 | 느린 경고음 |
| DANGER | 거리 ≤ 30cm 또는 TTC ≤ 1.5초 | 빨강 | 빠른 경고음 |
| NO SIGNAL | 에코 미수신 또는 허용 범위 벗어남 | 모두 꺼짐 | 무음 |

숫자를 계속 읽지 않아도 상황을 알 수 있도록 경고 단계마다 색상과 소리 패턴을 다르게 했다. 이 임계값은 시연을 위해 정한 것으로, 어떤 기준이 가장 좋은지는 아직 실험하지 않았다.

## 4. 소프트웨어와 관제 인터페이스

Arduino 펌웨어는 `거리,접근속도,TTC,상태` 순서의 CSV 형식으로 데이터를 내보낸다. Python 프로그램은 `pyserial`로 USB 포트를 읽고 파싱한 뒤 `Tkinter`로 거리, 속도, TTC, 상태 및 이벤트 로그를 갱신한다.

[Arduino 소스](../arduino/ThreatTrack_V5/ThreatTrack_V5.ino) · [Python GUI 소스](../python/threat_track_dashboard.py) · [GUI 데모 캡처](../assets/screenshots/dashboard-demo-screenshot.png)

화면에서 회전하는 레이더 선은 인터페이스 디자인이다. 센서 하나로 각도나 360도 위치를 측정할 수 있는 것은 아니다. 캡처 화면은 직접 실행한 프로그램의 **시뮬레이션 모드**다. COM5 충돌 이후 V5의 실시간 데이터 갱신 여부는 아직 재확인할 필요가 있다.

## 5. 무엇을 검증했고 무엇이 남았는가?

- **확인:** 초음파 거리값 시리얼 출력, 3색 LED 경보 동작, 부저 작동, Python 창 실행.
- **정확도 검증 아님:** 시리얼 사진의 8개 숫자는 거리 센서가 데이터를 출력했다는 증거일 뿐, 실제 거리 오차를 검증한 시험 결과가 아니다.
- **다음 실험:** 일정한 기준 거리에서 반복 측정하고, 물체가 움직이는 장면을 별도로 기록해 거리·속도·TTC 오차와 경고 지연을 계산해 보고 싶다. [실험 계획](VALIDATION_PLAN.md).
- **범위:** 교육·포트폴리오 프로토타입이며 군용 레이더, 3차원 추적기 또는 안전 인증 장치가 아니다.
